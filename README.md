# 지뢰 배틀 스윕 (Mine Battle Sweep)

웹 브라우저에서 바로 플레이하는 지뢰찾기 + 배틀 퍼즐 게임입니다.

## 실행 방법

1. `index.html` 파일을 브라우저로 엽니다.  
2. 또는 로컬 서버:

```bash
# Python
python -m http.server 8080
```

이후 `http://localhost:8080` 접속

## 조작

| 입력 | 동작 |
|------|------|
| 좌클릭 / 터치 | 칸 열기 |
| 우클릭 / 길게 누르기 | 깃발 |
| 숫자 칸 좌+우클릭 동시 | 깃발 수가 맞으면 주변 남은 칸 열기 |
| 숫자 칸 더블클릭 / 휠 클릭 | 코드 열기 (동일) |
| R | 다시 시작 |
| Esc | 일시정지 |
| 마우스 / ← → / A D | 사격 중 포신 이동 |
| 클릭 유지 / Space | 연사 |

## 기술

- HTML / CSS / JavaScript (빌드 도구 없음)
- Web Audio API 효과음
