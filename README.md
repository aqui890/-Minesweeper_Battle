# 지뢰 배틀 스윕

**Mine Battle Sweep** — 클릭은 탐색, 발견은 전투

브라우저에서 바로 플레이하는 지뢰찾기 + 사격 퍼즐 게임입니다.  
고전 지뢰찾기처럼 숫자를 읽고 깃발을 꽂되, 지뢰를 열었다고 바로 끝나지 않습니다. 사격으로 격추하면 그 칸은 제거되고 탐사를 이어갑니다.

## 실행

빌드 도구나 패키지 설치가 필요 없습니다. `index.html`이 진입점입니다.

### 로컬

저장소를 받은 뒤 `index.html`을 브라우저로 엽니다.

로컬 서버로 실행하려면:

```bash
python3 -m http.server 8080
```

이후 [http://localhost:8080](http://localhost:8080) 으로 접속합니다.

### GitHub Pages

이 저장소를 GitHub에 올린 뒤 정적 사이트로 배포할 수 있습니다.

1. 저장소를 GitHub에 푸시합니다.
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Build and deployment** 의 Source를 **Deploy from a branch** 로 선택합니다.
4. Branch는 기본 브랜치, Folder는 **`/ (root)`** 로 두고 저장합니다.
5. 배포가 끝나면 `https://<사용자명>.github.io/<저장소명>/` 에서 플레이할 수 있습니다.

## 플레이

타이틀에서 난이도를 고르고 **탐사 시작**을 누릅니다. 첫 클릭한 칸과 그 주변에는 지뢰가 배치되지 않습니다.

- 빈 칸을 열면 이어진 안전 구역이 함께 열립니다.
- 숫자 1~8은 인접한 지뢰 수이자, 그 지뢰와 싸울 때의 위험도 힌트입니다.
- 지뢰 칸을 열면 사격전으로 전환됩니다. 격추에 성공하면 지뢰가 제거되고 보드로 돌아옵니다.
- 사격에 실패하면 라이프가 1 줄고, 그 지뢰는 폭발한 뒤 사라집니다. 라이프가 0이면 패배입니다.
- 기본 라이프는 3입니다.

타이틀의 **사격 연습**에서 위험도 2·4·6·8 사격전을 따로 해볼 수 있습니다.

### 난이도

| 난이도 | 보드 | 지뢰 | 다음 스테이지 |
|--------|------|------|----------------|
| 초급 | 9×9 | 10 | 중급 |
| 중급 | 16×16 | 40 | 고급 |
| 고급 | 16×30 | 99 | — |

클리어하면 결과 화면에서 다음 스테이지로 이어갈 수 있습니다. 고급을 깨면 한 판이 끝납니다.

### 승리와 패배

- **승리:** 안전 칸을 모두 열거나, 남은 지뢰에 깃발을 정확히 모두 꽂습니다.
- **패배:** 라이프가 0이 됩니다.
- **노멀 엔딩:** 보드를 클리어합니다.
- **히든 엔딩:** 클리어하면서 전체 지뢰의 40% 이상을 사격으로 제거합니다.
- **배드 엔딩:** 라이프를 모두 잃습니다.

## 조작

### 보드

| 입력 | 동작 |
|------|------|
| 좌클릭 / 터치 | 칸 열기 |
| 우클릭 / 길게 누르기 | 깃발 |
| 숫자 칸에서 좌클릭 + 우클릭 동시 | 깃발 수가 맞으면 주변 칸 열기 |
| 숫자 칸 더블클릭 / 휠 클릭 | 위와 같은 코드 열기 |
| `R` | 현재 판 다시 시작 |
| `Esc` | 일시정지 |

### 사격

| 입력 | 동작 |
|------|------|
| 마우스 / `←` `→` / `A` `D` | 포신 이동 |
| 클릭 유지 / `Space` | 연사 |

빨간 탄은 피해야 합니다. 피격 3회 또는 제한 시간이 지나면 그 사격전은 실패입니다.

숫자가 클수록 지뢰가 많아지고 탄막이 거세집니다. 확실한 지뢰는 깃발로 표시하고, 맞설 지뢰는 사격으로 제거하면 됩니다.

### 위험도

| 위험도 | 사격 | 내용 |
|--------|------|------|
| 1~2 | 조준 사격 | 지뢰 1기. 느린 단발 |
| 3~4 | 제압 사격 | 지뢰 2기. 좌우로 피하며 격추 |
| 5~6 | 포화 사격 | 지뢰 3기. 더 빠르고 촘촘한 탄 |
| 7~8 | 보스 사격 | 눈이 달린 대형 지뢰와 쫄. 3방향 확산탄 |

위험도는 그 지뢰 주변에 이미 열린 숫자 중 가장 큰 값입니다. 숫자를 열기 전에 지뢰를 열면, 붙어 있는 칸의 숫자 전체를 기준으로 잡습니다.

## 프로젝트 구조

```
index.html     화면과 진입점
css/style.css  스타일
js/app.js      화면 전환, 입력, 진행
js/board.js    지뢰찾기 보드
js/battles.js  위험도별 사격전
js/audio.js    효과음
```

## 기술

- HTML, CSS, JavaScript. 프레임워크와 빌드 단계 없음
- 사격 화면은 Canvas
- 효과음은 Web Audio API
- 글꼴은 [Orbitron](https://fonts.google.com/specimen/Orbitron), [Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR) (Google Fonts)

데스크톱과 모바일 브라우저에서 플레이할 수 있습니다. 최신 Chrome, Edge, Firefox, Safari를 기준으로 합니다.
